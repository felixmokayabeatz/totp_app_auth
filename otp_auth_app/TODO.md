## Code Notes

- Reviews: `lib/services/app_rating_service.dart`, `lib/screens/login_screen.dart`, and rating endpoints in `lib/config/app_config.dart`.
- Remote sign-out heartbeat: `lib/main.dart`, `lib/services/sync_service.dart`, `lib/screens/device_sessions_screen.dart`, and backend `otp_backend/api/views.py`.
- Accent color: `lib/providers/theme_provider.dart`; many screens still use local `_accent` constants or hard-coded colors.
- Backup-code PDF authentication: `lib/screens/settings_screen.dart`, `lib/services/sync_service.dart`, `lib/services/app_lock_service.dart`, and `lib/services/biometric_service.dart`.
- Google Authenticator import: parser support already exists in `lib/services/otp_import_service.dart`; scan/save flows are in `lib/screens/add_account_screen.dart` and `lib/screens/settings_screen.dart`.
- Offline-first mode: `lib/services/sync_service.dart` currently defaults sync to enabled; startup/session flow is in `lib/main.dart`, `lib/screens/splash_screen.dart`, `lib/screens/login_screen.dart`, and `lib/providers/auth_provider.dart`.
